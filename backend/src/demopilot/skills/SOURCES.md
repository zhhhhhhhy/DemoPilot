# Skill method provenance

These DemoPilot skills are original, project-specific instructions. They adapt workflow ideas rather than copying third-party skill text.

- OpenAI Skill Creator: progressive disclosure, precise triggering, deterministic helpers, observable verification.
  <https://github.com/openai/codex/tree/main/codex-rs/skills/src/assets/samples/skill-creator>
- Anthropic Web Application Testing: start the application, inspect rendered state, then execute Playwright actions and capture browser evidence.
  <https://github.com/anthropics/skills/tree/main/skills/webapp-testing>
- Anthropic Engineering Code Review: review correctness, security, performance, maintainability, and tests with evidence.
  <https://github.com/anthropics/knowledge-work-plugins/tree/main/engineering/skills/code-review>
- Browserbase UI Test Skill: task-oriented browser assertions with a bounded interaction budget.
  <https://github.com/browserbase/skills/tree/main/skills/ui-test>

Each upstream repository keeps its own license. No upstream executable or source file is bundled here.
