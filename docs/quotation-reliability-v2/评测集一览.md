# 100个业务组合一览

每个应用实现十种定价方式；组合按应用共享工作流，因此100个组合只对应10类应用。前3类（30组合）用于开发，后7类（70组合）不参与CLI结果驱动的调试。商品、客户和金额是合成配置，公开材料只提供业务模式。

每个组合v1有6条路径，v2有7条路径：正常报价审批确认、修改后审批失效、错误输入/角色拒绝与恢复、工作流专属规则、定价边界、跨报价记录隔离，v2再增加配送及其审批影响。每一步的预期金额、状态、修订号和历史数量分别存于公开和私有验收JSON中。

全部两组、两个版本合计规划2600条最终独立浏览器路径（开发780、保留测试1820）；运行和通过数量以最终结果为准。不能把这些路径或组合写成独立客户数量。
